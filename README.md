# Brass Legacy Showcase

Create a premium, modern, fully responsive STATIC WEBSITE DEMO for a traditional Indian brass cookware and utensils shop.

This is ONLY a visual client demo. Do not build backend functionality, authentication, database, admin panel, payment system, shopping cart, checkout, or product management.

Business

A premium Indian brass cookware and utensils shop selling traditional brass kitchenware.

Main Purpose

The website should make the business look premium and trustworthy online and showcase its products beautifully.

Customers should be able to:

Browse the product catalogue

View attractive product cards

See product names and prices

Click a WhatsApp enquiry/order button

The WhatsApp buttons can use a placeholder number for the demo.

Design Direction

Create a luxurious Indian brassware aesthetic.

Use:

Warm cream/off-white backgrounds

Elegant brass/gold accents

Premium dark typography

High-quality realistic brass cookware photography

Large product photography

Clean whitespace

Sophisticated typography

Subtle shadows

Premium cards

Smooth hover animations

Elegant section transitions

Avoid:

Generic template appearance

Excessive animations

Bright colors

Cheap-looking gradients

Overcrowded layouts

Restaurant-style design

Fashion/e-commerce-style design

The final website should feel like a premium traditional Indian brassware showroom.

Important

This is a STATIC CLIENT DEMO ONLY.

Prioritize visual quality, premium UI, typography, spacing, product photography and responsive design over functionality.

Do not build backend functionality.

Do not create an admin panel.

Do not create authentication.

Do not create checkout or payments.

Do not create a database.

Make the website look polished enough that a real local business owner would immediately understand how their finished website could look.
